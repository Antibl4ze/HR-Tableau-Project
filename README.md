# HR Analytics Dashboard (Tableau)

An interactive Tableau dashboard built on a dataset of about 8,950 employee records.

## What it shows
- Employee demographics (gender, age, education level)
- Headcount by department and location, including a map
- Hiring and termination trends
- Salary and performance rating breakdowns

## Files
- `HumanResources.csv` – the dataset
- `link to the project` – link to the dashboard on Tableau Public
